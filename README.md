## 👨‍💻 Sobre mim

Sou **Mateus Alves**, estudante de **Gestão da Tecnologia da Informação (GTI)**.

Gosto bastante da parte prática da tecnologia: criar uma interface, fazer ela conversar com uma API, entender o que acontece no back-end e organizar os dados no banco.
